# TrubaVPN — веб-админка

Красивая чёрно-белая админ-панель на Python (Flask), которая работает
с той же базой PostgreSQL и панелью Remnawave, что и Ваш Telegram-бот.
Повторяет весь функционал админ-панели бота.

## Авторизация (как вы просили)

1. Админ открывает сайт и вводит свой **Telegram ID**.
2. Бот присылает ему в ЛС **6-значный код подтверждения**.
3. Админ вводит код на сайте — и попадает в админку.

Список админов берётся из переменных `ADMIN_ID_1` / `ADMIN_ID_2` — тех же,
что у бота. Код действует 5 минут, не более 5 попыток ввода.

> **Один бот на всё.** Укажите в `BOT_TOKEN` токен вашего основного
> **VPN-бота** (тот же, что в `.env` файла `bot.py`). Тогда коды
> подтверждения и сообщения пользователям приходят из этого же бота,
> а не из отдельного «админ-бота». Сайт только вызывает
> `sendMessage`/`sendPhoto` и не конфликтует с long-polling бота —
> один токен можно безопасно использовать в обоих процессах.
> Админ должен хотя бы раз нажать /start у этого бота, чтобы получать коды.

## Функционал

- **Статистика** — пользователи, активные подписки, онлайн, выручка.
- **Подписчики** — поиск по ID/username, карточка пользователя.
- **Карточка пользователя** — добавить/снять/установить дни, лимит устройств,
  белые списки, вкл/выкл подписки, сообщение через бота, история платежей, устройства.
- **Кто онлайн** — список активных за последние 3 минуты.
- **Выдать ключ** — ручная выдача подписки с уведомлением.
- **Тикеты** — переписка, ответы (с шаблонами), закрытие/переоткрытие.
- **Промокоды** — создание/удаление (дни, скидка, тариф).
- **Платежи** — история и общая выручка.
- **Медиа-партнёры** — добавление/удаление, процент.
- **Рассылка** — всем / только платившим.
- **Опрос** — отзывы и средний рейтинг.
- **Шаблоны** — быстрые ответы для поддержки.
- **Настройки** — DND и уведомления о покупках.

## Установка

```bash
cd trubavpn-admin
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env            # заполните свои значения (те же, что у бота)
```

### Переменные окружения

Скопируйте значения из `.env` бота. Главное — чтобы совпадали:
`BOT_TOKEN`, `DATABASE_URL`, `REMNAWAVE_URL`, `REMNAWAVE_TOKEN`, `SUB_BASE_URL`,
`SQUAD_UUID*`, `ADMIN_ID_1`, `ADMIN_ID_2`.
Дополнительно для сайта:
- `SECRET_KEY` — случайная строка (напр. `python3 -c "import secrets;print(secrets.token_hex(32))"`).
- `AUTH_CODE_TTL_MIN` — время жизни кода (по умолчанию 5).

## Запуск

Для разработки:
```bash
python3 app.py
```

Для продакшена (gunicorn):
```bash
gunicorn -w 2 -b 0.0.0.0:5000 app:app
```

Первый запуск автоматически создаёт таблицу `web_auth_codes` в той же БД
(остальные таблицы уже создаёт бот; колонка `templates.buttons` добавляется
автоматически). Основной VPN-бот должен быть запущен — через него
(один и тот же `BOT_TOKEN`) отправляются и коды, и сообщения.

### За Nginx (рекомендуется HTTPS)

```nginx
server {
    server_name admin.trubavpn.ru;
    location / { proxy_pass http://127.0.0.1:5000; proxy_set_header Host $host; }
}
```

## Структура

```
app.py          — все маршруты Flask
config.py       — чтение переменных (как у бота)
db.py           — пул PostgreSQL
remnawave.py    — клиент Remnawave API
telegram.py     — отправка сообщений/кодов через Bot API
templates/      — HTML (Jinja2, делимитеры [[ ]])
static/style.css— чёрно-белая тема
```

## Безопасность

- В админку пускаются только Telegram ID из `ADMIN_IDS`.
- Код подтверждения одноразовый, с ограничением попыток и времени.
- Обязательно используйте HTTPS и свой `SECRET_KEY` в продакшене.
